# 完蛋企业（离线安卓版 · LV.999.1）

## 安装

直接安装工作文件夹中的 **`完蛋企业.apk`**。应用完全离线，不申请联网权限。

## 开屏与激活

- 启动时显示 **荆州学院开屏页**：纯黑背景、荆州学院校徽/校名和底部「AI 教育版」标识，固定居中，画面不再移动。
- 开屏图标已比上一版缩小；系统启动页原来那个白色底的旧图标也已去掉，冷启动直接黑底进入荆州学院开屏。
- 停留约 0.8 秒后，整页做 **约 460ms 的渐变消失**，直接过渡到消息页；未激活时则渐变过渡到激活页。
- 未激活时可使用 **`#66CCFF`** 或 **`2513`** 激活，激活后永久记住。
- 也可以点「**不激活，进入试用（信息只读）**」；修改资料时会先要求激活码。

## 一级页面

底部五个入口现在都可以点击：

- **消息**：你提供的企业微信消息截图，顶部状态栏已裁掉。
- **文档**：新加入的文档页；两条文档、搜索、新建都可以点，离线演示会给出提示。
- **通讯录**：新加入的通讯录页；智能机器人、外部联系人、添加外部联系人、搜索都可以点。
- **工作台**：原来的请假程序；工作台底部的「消息 / 文档 / 通讯录 / 工作台 / 我」也已接通。
- **我**：个人页；进入时顶部的「点击姓名或头像可以修改」提示已去掉。
- **帮助**：我 → 帮助 内含完整使用说明，包含下面的加载、水印、设置、请假和隐私说明。

### 进入请假的加载过程

从工作台点「学生请假」或「学工系统」后：

- **0 ~ 1 秒**：黑屏，顶部「学生请假」标题下有一条蓝色进度条，走到 50%。
- **1 ~ 3 秒**：切换为白屏，黑色地址栏显示「学生请假」（不再显示长网址），白色页面加载 2 秒。
- **3 秒后**：进入真正的请假列表。
- 整个加载过程忽略手机系统状态栏；加载中按返回可以直接退回工作台。

### 通讯录水印

通讯录页面的水印会按照 **我 → 设置** 里填写的信息自动生成，不再是固定文字：

- 第一行：`姓名@荆州学院`
- 第二行：`学号 yyyy-MM-dd HH:mm`
- 日期和时间会随系统时间自动更新；修改姓名或学号后，重新进入通讯录即可看到新水印。
- 原截图里烘焙进去的真实姓名、学号和水印已经从打包图片中抹除。

## 我的设置

从 **我 → 设置** 进入（未激活会先要求激活码）：

- **性别**：男生 / 女生，切换后使用对应性别的档案，并同步默认头像。
- **个人信息**：姓名、学号、学院·专业·班级、手机号。
- **请假设置**：请假理由、学年、学期、请假性质、辅导员姓名。
- 保存后会同步到：我的页姓名和头像、请假列表/详情、通讯录水印。

**自定义时间不在设置里**：仍然保留在 **请假详情右上角 `⋮`**，而且只修改当前打开的这一条记录。

## 请假列表

- 现在共有 **1 条「已通过、未销假」 + 6 条「已销假」 = 7 条记录**。
- 未销假记录的开始时间按当前时间 **前一天** 自动生成；6 条已销假的开始时间从 **2 天前到 7 天前** 依次排列。
- 结束时间统一为开始时间 +2 小时，请假天数按 0.08 天计算，与之前保存的规则一致。
- 列表字号整体加大约 2，行间距加大 50%，卡片外边距和内边距翻倍，顶部返回/更多/新增图标也相应放大。
- 未销假卡片显示「未销假 + 已通过」；已销假卡片只显示一个「已销假」。
- 七张卡片都可以点开。

## 请假详情

### 未销假

- 保持之前的头像、资料卡、请假信息、销假信息、审核流程。
- 底部保留「定位销假 / 续假申请」，高度 44、底栏 72、等宽。

### 已销假

- 顶部增加浅绿色「✔ 已销假」状态条。
- 「销假信息」自动填写：销假状态、销假类型（定位销假）、销假时间、销假人、销假说明（已回学校），并增加「合照样例 / 学生合照」占位。
- **没有底部「定位销假 / 续假申请」按钮**。
- 其余字体、间距、字号与已调好的请假详情保持一致，没有改动。

## 隐私说明

- 新素材里的真实姓名、学号、手机号、头像、水印均未打进 APK；通讯录水印改为运行时根据设置生成，请假详情使用「示例女生」等演示资料。
- 默认资料：示例用户 / 示例女生、学号 `2025000002`、手机号 `12345678901`，都可以在设置里改成自己的信息。
- 头像默认女生头像，支持男生头像和自定义上传；自定义上传按 224:200 居中裁切，压缩为 448×400。
- 应用不申请任何权限、不联网、不读取相册（只有主动选择自定义头像时才调用系统图片选择器）。
