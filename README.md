1. 安装 `app/完蛋企业-LV.999.1.apk`。
2. 首次启动输入激活码 `#66CCFF` 或 `2513`，也可选择试用。
3. 详细功能见 `README-使用说明.md`；应用内「我 → 帮助」也包含完整说明。

## 构建

需要 JDK、Android SDK、build-tools 36.0.0、android-36.1：

```powershell
cd source/LeaveApp
./build.ps1
```

构建脚本会自动生成签名文件（如果不存在）。公开仓库不包含原发布签名，重新构建的 APK 不能直接覆盖官方发布包升级。
